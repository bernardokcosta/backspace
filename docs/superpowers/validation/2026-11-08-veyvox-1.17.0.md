### macOS launch root cause and bounded packaging repair

The maintainer explicitly requested correcting all remaining blockers, not merely
reporting failures. Source investigation found the concrete mismatch:

- Pinned electron-builder 26.18 `electronMac.js` uses
  `appInfo.sanitizedProductName` (Veyvox) for helper bundle/executable paths,
  independently of retained `appInfo.productFilename` (Backspace Fork).
- Electron 45.2.1's [mac main delegate](https://github.com/electron/electron/blob/v45.2.1/shell/app/electron_main_delegate_mac.mm)
  first checks Electron Helper, then helpers named from `GetApplicationName()`.
  [That accessor reads CFBundleName](https://github.com/electron/electron/blob/v45.2.1/shell/common/application_info_mac.mm),
  retained as Backspace Fork. If neither path exists it calls `LOG(FATAL)` with
  `Unable to find helper app`, explaining a pre-renderer native trap despite a
  valid signature.
- A regression using the **actual pinned `createMacApp`** and unexecuted fixture
  files reproduces Veyvox helpers beside retained Backspace Fork CFBundleName.
  The new layout verifier rejects that output; the packaging correction repairs
  it without executing a Mac binary or touching a real profile.

The existing `macSign.js`/`afterPack` owner now preflights helper names and aligns
only the helper bundle paths, executable names and `CFBundleExecutable` fields
before fuse flipping/final signing. It never rewrites main CFBundleName/app ID,
helper identifiers/display names or binary content, and adds no entitlements,
trust exceptions, fuse changes or dependency. Collisions/inconsistent inputs
abort before the first rename; an IO failure aborts packaging, not the gate.
Both real package and installed verifiers read the resulting helper layout.
The initial missing implementation/order regression was RED, then four focused
Mac fixture/real-packager tests passed, including idempotence and no-overwrite
preflight cases. Actual native runner launch acceptance remains necessary.

The remaining baseline CodeQL #71 was also addressed at its existing static
catalog reader: script closing tags accept whitespace/browser-tolerated trailing
attributes and case variants. Five format regressions observed RED then GREEN.
